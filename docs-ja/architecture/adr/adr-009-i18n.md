# ADR-009：多言語対応（i18n）

**ステータス**：決定済み

## 決定

初期スコープはja/enの2言語のみ。標準的なi18nライブラリ（i18next等）でリソースファイル（`locales/ja.json` / `locales/en.json`）方式を採用し、自作の文言管理は行わない。

## 補足

- 初回起動時にOSロケールを自動検出し、設定画面から手動切替も可能にする（Everything Configurable）
- ja/en以外の対応は当面Non-goals

## フォント

- UIフォント：IBM Plex Sans JP（ja/en両対応）
- 等幅（URL・コード）：IBM Plex Mono。日本語の文字は IBM Plex Sans JP で表示する
- どちらもアプリに同梱し（`@fontsource/*`、SIL OFL 1.1）、OS に入っている書体に頼らない

### 改訂（2026-10-12、T4-5a）

当初はメイリオと JetBrains Mono にしていた。メイリオは Windows にしか入っておらず、macOS ではヒラギノ、Linux では入っている書体まかせになり、3 OS で見た目がそろわなかった。また、画面が味気ないという課題に対し、色を足さずに個性を出せるのは書体だったため、和文・欧文・等幅が同じ設計の一家である IBM Plex にそろえた。比べた案は、BIZ UDPゴシック＋JetBrains Mono（読みやすいが Windows 標準と同じ字形で個性が出ない）、LINE Seed JP＋Geist Mono（個性は強いが小さい文字で詰まって見える）、OS の標準書体（同梱は要らないが Linux でそろわない）。

同梱するのは使う太さ（Sans JP の 400・700、Mono の 400）だけにする。太さを増やすときは、`app/src/renderer/src/main.tsx` に読み込みを足す。
