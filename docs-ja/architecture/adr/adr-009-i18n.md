# ADR-009：多言語対応（i18n）

**ステータス**：決定済み

## 決定

初期スコープはja/enの2言語のみ。標準的なi18nライブラリ（i18next等）でリソースファイル（`locales/ja.json` / `locales/en.json`）方式を採用し、自作の文言管理は行わない。

## 補足

- 初回起動時にOSロケールを自動検出し、設定画面から手動切替も可能にする（Everything Configurable）
- ja/en以外の対応は当面Non-goals

## フォント

- UIフォント：メイリオ（ja/en両対応、フォールバック管理不要）
- コード表示：JetBrains Mono
